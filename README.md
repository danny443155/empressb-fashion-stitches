# EmpressB Fashion Stitches — starter website

A responsive luxury-style website starter using burgundy, gold and cream branding. It includes a portfolio, sample product gallery, currency display toggle, custom-order request form, appointment request form and WhatsApp contact.

## Preview
Unzip the project and open `index.html` in a browser. An internet connection is needed for Google Fonts and remote images.

## Before publishing
- Replace the sample product names, photos and prices with your actual items.
- The USD prices are illustrative, not live exchange-rate conversions.
- Confirm the WhatsApp number in `app.js`.
- Test the forms on a phone and desktop.

## What is not included yet
This is a front-end starter, not a complete full-stack store. It does not yet include secure customer accounts, a database, persistent order tracking, admin product management or online payment processing. Those require backend setup, security configuration and testing before launch. The forms currently open WhatsApp with a prefilled message.

## Free-tier hosting route
### Cloudflare Pages
1. Create a GitHub repository and upload `index.html`, `styles.css`, `app.js`, and `README.md`.
2. In Cloudflare, open Pages and create a project connected to your repository.
3. For this plain static site, choose no build command and use the repository root as the output directory.
4. Deploy, then test the provided `pages.dev` address.

### GitHub Pages
1. Upload the files to a GitHub repository.
2. Open repository Settings → Pages.
3. Select your branch and root folder as the publishing source and save.
4. Wait for deployment and test the published address.

Free plan terms and limits can change, so check the current provider terms before relying on it for business operations. A custom domain is optional; secure online payments may incur transaction fees.
